## 2. 三个模块各做什么

### 2.1 物理作战域三维监控（Monitor）

- 枚举全部敌方弹药情报（`Type = 1`），与本方每个单元做**相对速度 → 最近接近点 CPA** 计算。
- 判定条件：`CPA ≤ 3 km` 且 `预计命中 ≤ 900 s` 且 `距离 ≤ 90 km`。
- 输出到内部 `self._threats`：`{我方guid: {弹型, 弹速, 距离, CPA, 剩余时间}}`。
- **不下任何指令**，只供下游两个模块使用。

日志：`威胁[苏-35S #1] ← AGM-88B 弹速3000km/h 距离45.1km CPA0.8km 预计60s命中`

### 2.2 空战单元自卫（Evade）

| 条件 | 动作 |
| --- | --- |
| 距离 ≤ **1.2·d0(弹V0, 我机速)** 或 ≤ 25 km 或 ≤ 60 s 命中 | **正横机动**（转到与弹速度矢量垂直的方向）+ 加力 |
| 距离 < 20 km 且弹速 > 我机 1.5 倍 | 正横机动 + 降高 305 m（`VERTICAL_JINK`，**默认关**） |
| 弹速 < 500 km/h / 规避超 120 s / 威胁消失 | 结束规避，**回原任务** |

> **触发门限**按物理包线实时算（`EVADE_USE_D0 = True`，`d_turn = 1.2·d0`），
> 但 d0 必须用**这枚弹观测到的最高速**当 V0（弹已经减速时用当前速度算，d0 会塌到 3 km，
> 于是“13.5 km、24 秒后命中”都不触发规避——这就是上一局飞机不躲的原因）。
> 另加两条硬触发：`≤ 25 km` 或 `≤ 60 s 命中` 无条件规避。
>
> **动作是正横（beam）不是掉头**：`EVADE_MODE = 'beam'`。弹从正后方追来时，
> “掉头”在几何上等于继续往前飞（画面上完全看不出在规避，效果也最差）；
> 正横是 90° 转向，能逼导弹持续修正、脱靶量最大。想退回文档原写法：
> `EVADE_MODE = 'away'`。

**控制权**：只有真正要机动时才 `withdraw_from_mission`（接管），在此之前完全交给任务托管——
所以飞机不会因为“远处有枚弹”就被拽出任务区。规避结束时自动 `assign_to_mission(原任务名)`。

**规避航路不每周期重画**：`REPLOT_SEC = 30`（或目标点挪动 > 5 km）才重发，否则一直重置转向会让飞机“原地抖”。

日志：`规避[苏-35S #1] 接管控制（退任务 右制空）ok` / `规避结束[...]（弹速降到 400）→ 回任务 右制空 ok`

### 2.3 空空作战（AirCombat）

1. 从挂载里挑**对空射程最远**的那型弹（读挂载的 `AirRangeMax`，单位海里；
   缺字段就查 `model.db`）。**只认制导武器 Type=2001**——机炮（Type 2004，
   如 30mm Gsh-30-1 的 `AirRangeMax` 写着 1 海里）和诱饵（2006/2007）一律排除。
2. 临界距离 `d0 = T·(V0−Va)² / (2·(V0−Vterm))`，`T = 240 s`、`Vterm = 500 km/h`。
3. 开火条件：`距离 ≤ min(0.8·d0, 0.7×该弹最大射程)`、`距离 ≥ 5 km`、
   **目标高度 / 本机高度 ∈ [0.9, 1.2]**。
   （只按 d0 不看射程的话，拿 18 km 的 R-73 去打 70 km 外的目标必然脱靶。）
4. 同一目标 30 秒内不重复分配；距离在 `0.6·d0` 以内打 2 发，否则 1 发。

**V0（我方弹初速）**：平台没有这个字段，代码里三层兜底——
① `V0_TABLE` 手填；② **自动标定**（我方打出的弹出现为情报时，取其速度作为初速）；
③ 兜底 `V0_DEFAULT = 4000 km/h`。

日志：`开火[苏-35S #2] → 敌机#1 武器2056×2 距离30.0km ≤ 0.8·d0=73.2km (V0=4000 Va=900 高度比1.00)`
标定时：`标定弹速：武器2056 初速≈4200 km/h`

**每 20 个周期有一行诊断**，专门用来定位“为什么不开火”：

```
空战诊断：敌机情报3 架；未开火原因 距离=2 高度比=1 规避中=1 无空战弹=0
```

`无空战弹` 表示这架飞机的挂载里查不到对空射程（会用 `model.db` 的 `DataWeapon.AirRangeMax`
兜底，再不行就跳过）；`距离` 表示目标还在 0.8·d0 之外。

## 3. 客户端消息栏（给操作手看的）

`agent_message_text()` 推送到客户端“智能体输出”消息栏，参数在文件顶部：

```python
MSG_ENABLE = True          # 开关
MSG_MAX_PER_CYCLE = 3      # 每周期条数上限，防刷屏
MSG_DEDUP_SEC = 30.0       # 同一句话 30 秒内不重复
MSG_REPORT_FULL = True     # 每周期一条“谁在被攻击”的汇总
```

实际会看到的消息：

```
【被锁定】3 架：神经元#1(7s)、苏-27#5(51s)、苏-35#1(99s)      ← 按命中时间排序
【规避】神经元#1 开始规避（弹速1428 距离3.4km 门限24km）
【恢复】神经元#1 规避结束（弹速降到 400）→ 回任务 神经元1
【开火】苏-35S #2 → 敌机#1（30km，2056×2）
【出界】苏-30SM #3 距任务区 102km，已召回
```

排序按“还有多少秒命中”，所以消息栏里**第一行永远是最危险的那架**。

## 4. 两条护栏

### 4.1 边界守卫

- 任务区用**手填表** `MISSION_AREAS`：`任务名 -> (中心纬度, 中心经度, 半径km)`。
  表里没有的任务，回落到「起飞点 + `DEFAULT_AREA_KM`（70 km）」。
- `SOFT_NM = 20`（只记录）/ `HARD_NM = 50`（真正干预）：
  出界超过 50 海里 → `attack_drop_target_all()` 放弃追击 + 画航线回飞到“区内 20 km 处”。

> 你在客户端把任务区拖大拖小之后，改一下 `MISSION_AREAS` 里对应那一行的半径即可。

### 4.2 禁航区

- `NO_FLY_ZONES = ()` 目前**空**。填成 `(('禁航区A', [(lat, lon), (lat, lon), ...]),)` 即生效。
- 所有要画的航路点都会先过一遍 `_safe_point()`：若落在多边形内，沿“目标→本机”方向退到区外，
  再向外多推 5 km。
- 日志：`禁航区[禁航区A]：目标点在内，已外移 12km`

## 6. 第一次实盘要盯的 4 行日志

| 日志关键字 | 说明 | 不符合预期时改哪里 |
| --- | --- | --- |
| `威胁[...] ←` | 是否真的识别到来袭弹 | 调 `THREAT_CPA_KM` / `THREAT_MAX_KM` |
| `规避[...] 接管控制` | 是否在门限距离才接管 | 调 `EVADE_TURN_HI_KM` / `EVADE_TURN_LO_KM` |
| `开火[...]` | d0 是否合理、是否常被拒 | 看 `V0` 标定值；或手填 `V0_TABLE` |
| `出界[...]` | 是否频繁触发 50nm 硬界 | 改 `MISSION_AREAS` 半径或 `HARD_NM` |

另外 `TAC 汇总：周期N 威胁x 自卫y 开火z 出界纠正w 指令n` 每 20 个周期一行，可用来判断负载
（`指令n` 应远小于 120，超过说明阈值太松，需要收紧）。

## 7. 怎么验证：平台开关怎么设、按什么顺序试

> 结论先说：**自动规避必须关**；**自由开火建议先关（改成"限制开火"）**，
> 因为只有关掉之后，"每一枚打出去的弹"才能确定是我们分配的，否则分不清是平台自己打的还是我打的。

### 7.1 平台条令开关对照表

| 平台开关（条令面板） | 验证时设成 | 为什么 |
| --- | --- | --- |
| 自动规避（飞机） | **关** | 两套规避同时跑，永远不知道是谁在转；平台那套还要等弹速降到 0 才动，会把我们的规避覆盖掉 |
| 武器控制状态-对空 | **限制开火**（先试这个） | 平台不再自动开火，`【开火】`消息对应的就是我们的 `attack_weapon_allocate_to_target` |
| 武器控制状态-对空（第二步） | 不開火 | 如果"限制开火"下我们的手动分配仍被拒，就说明手分配也受 WCS 约束，这时改用"自由开火 + 我们只做距离判定" |
| 忽略规划航线（攻击时） | **否** | 设"是"的话，一旦有目标平台就无视我们画的规避/回飞航线 |
| 燃油状态-返航 / 武器状态-返航 | 否 | 设"是"会半路自己返航，规避和开火都测不出来 |
| 飞机数低于编队要求自动返航 | 关 | 否则少一架就整队撤 |

### 7.2 分四步验证（用模块开关，一次只开一个）

文件顶部有四个开关，改完重新加载智能体即可：

```python
ENABLE_MONITOR = True       # ① 只算不动手
ENABLE_EVADE = False        # ②
ENABLE_AIR_COMBAT = False   # ③
ENABLE_BOUNDARY = False     # ④
```

| 步 | 开什么 | 看什么 | 判据 |
| --- | --- | --- | --- |
| ① | MONITOR | 消息栏`【被锁定】`、日志`威胁[...]` | 与你肉眼看到"谁在被打"一致（可以有 1~2 架延迟，因为情报有刷新周期） |
| ② | +EVADE | `规避[...] 掉头`、飞机是否及时转向 | 掉头距离 = 1.2·d0，日志里有门限值；转向后是否有弹追不上 |
| ③ | +AIR_COMBAT | `空战诊断`、`【开火】` | 若`敌机情报0 架`→是探测问题；若`无空战弹=N`→是挂载问题；若`距离` 一直卡着→是 d0/射程问题 |
| ④ | +BOUNDARY | `出界[...]` | 只在真的离开任务区 +50 海里时出现，不应每周期刷 |

每局开始日志里会有三行"这个局是什么设置"：

```
AGENT_BUILD=2026-11-16-TAC-RED-02 ...
本次实验设置 RUN_TAG = A:平台规避关+限制开火
能力自检（开局）：在空/可用飞机 18 架，其中带对空弹 16 架
   · 苏-35S #1: 2056×6 射程111km
   · 苏-57 #1: 2104×4 射程120km
   · 苏-27 #3: 无对空弹
```

`RUN_TAG` 是你自己填的，改一次记一次，回看日志就知道这一局是哪种组合。

### 7.3 建议先做的一次"最小对照"

想证明"我们的规则优于平台默认"，最小可信的对照是**同一种子、同一想定、同一初始态势**跑两局：

| 局 | 平台自动规避 | 平台对空自由开火 | 我们的模块 |
| --- | --- | --- | --- |
| A | 开 | 开 | 全关（`ENABLE_* = False`） |
| B | 关 | 关 | 全开 |

比三个数：**飞机存活数 / 被击落时刻 / 打出去的空空弹数**。A、B 差异才是我们的贡献。
只跑 B 不行——你无法排除"本来就该活"。
