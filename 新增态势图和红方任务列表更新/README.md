红方中部核心地带部署思路：红方核心目的是保护船只安全抵达登陆区不断取得登陆区得分。蓝方对我船只的主要威胁有海马斯系统和反舰导弹排、小炸弹、轰炸机158C和154C。在战局初期需要派出神经元无人机和挂载“铁锤”的阵风快速解决海马斯系统和反舰导弹排，完成此目标需要两个前提：一是取得海岸线一线的制空权，防止敌方飞机快速前冲解决我方无人机；二是要对敌方爱国者地空导弹做出应对，以防其防空导弹解决我无人机。针对前提一：苏57，苏27等飞机开局前冲利用代际优势提供空中压制。针对前提2：给出一种针对爱国者的解决方法，苏30SM、苏34等飞机携带反辐射对地弹，若敌方爱国者开火攻击我对地无人机，反辐射弹拥有较远射程，可以快速发射，损毁爱国者雷达装置、发射装置和动力系统，S70分批次出动（防止弹药浪费）进一步对爱国者进行毁伤，最后在爱国者动力装置损毁情况下，使用伊斯坎德尔进行远程陆陆打击，彻底消灭爱国者，进一步取得蓝方内陆制空权。而后即可使用TB2无人机进入内地，对其余地面设置进行打击摧毁。

如[图](尺规作图.png)所示，蓝色折线是蓝方海马斯系统的对海最远打击范围。总体策略是B、C两个区域的船只统一向B登陆区域前进，在登陆区可以进行多船联合防空，提高存活率。战前移动方面，B区船移动到A点，C区船移动到B点，效果为船只在AD、BE段完全安全，在进度15%左右，会进入打击范围，而基于上述策略，我方会在5%~8%损毁敌方海马斯系统和反舰导弹排，仍留有冗余时间，容错率较高。D区域船只开局即在打击范围，所以先移动到C点，沿着安全区域边缘移动，接近登陆区到F点时间也为15%，之后可以直线驶入登陆区。
