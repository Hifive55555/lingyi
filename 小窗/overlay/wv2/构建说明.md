# 小窗窗口宿主（WebView2）

小窗的页面仍然是 `web/` 里那套 HTML/CSS/JS，**渲染器换成随包自带的 WebView2 宿主**，
不再调用目标机上的 `msedge.exe`。

## 为什么不用 Edge

实测目标机（Win11 + Edge 141）上，`launcher.py` 自己拉起的 `msedge.exe --app=...`
实例经常不完成导航：窗口标题停在 `127.0.0.1_/`、内容纯灰，而同一时刻同一端口
从外部请求返回 `HTTP 200`。`browser.out` / `launcher.log` 里的线索是

```
EDGE_IDENTITY: Get Default OS Account failed (kImplicitSignInFailure, 0x80070005)
启动 WebView2 宿主失败：[WinError 5] 拒绝访问。: 'C:\Users\A\AppData\Local\灵弈小窗'
```

即这台机的 `%LOCALAPPDATA%`（`C:\Users\A\AppData\Local`，账户改过名）**不可写**：
Edge 的默认 profile 就落在 `%LOCALAPPDATA%\Microsoft\Edge\User Data`，建不出来 →
灰屏；WebView2 用 `%LOCALAPPDATA%` 当 UDF → 直接 `0x80070005`。
所以：**不要传 UDF 到 `%LOCALAPPDATA%`**，让宿主用 exe 同级目录。

## 文件

| 文件 | 作用 |
| --- | --- |
| `host.cs` | 宿主源码（WinForms + WebView2，自绘标题栏：拖动 / 最小化 / 关闭） |
| `overlay_wv2.exe` | 已编译好的宿主（x64，10 KB），部署时直接拷，目标机不需要编译器 |
| `Microsoft.Web.WebView2.Core.dll`<br>`Microsoft.Web.WebView2.WinForms.dll` | WebView2 SDK 托管程序集（NuGet `Microsoft.Web.WebView2` 1.0.2903.40，net462） |
| `WebView2Loader.dll` | 原生加载器（NuGet 同包 `runtimes/win-x64/native`） |

运行时用的是目标机已装的 **WebView2 Runtime**（本机 141.0.3537.71，Win11 自带），
不需要联网、不需要装任何东西。

## 用法

`launcher.py` 会自动拉起：

```
overlay_wv2.exe <url> <宽> <高> <UDF>
```

- `UDF` 传空 → 宿主用 exe 同级的 `overlay_wv2.exe.WebView2`（默认，也是唯一验证过可写的位置）
- 想换位置：`LY_OVERLAY_UDF=D:\...\logs\wv2` 再启动 launcher
- 宿主找不到/启动失败时，`launcher.py` 退回 `msedge.exe --app`（仅作兜底）

## 重新编译（一般不需要）

在目标机或任意有 .NET Framework 4.x 的 Windows 上：

```bat
cd /d <本目录>
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe ^
  /platform:x64 /optimize+ ^
  /r:Microsoft.Web.WebView2.Core.dll /r:Microsoft.Web.WebView2.WinForms.dll ^
  /r:System.dll /r:System.Drawing.dll /r:System.Windows.Forms.dll ^
  /out:overlay_wv2.exe host.cs
```

诊断日志写在 exe 同级的 `wv2_err.log`（普通权限即可写）。
