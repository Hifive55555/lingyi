## 0 全局约定（五张图通用）

| 项 | 规定 |
|---|---|
| 输出 | `paper/schematics/schema-N-<slug>.svg` + 同名 `.pdf` + `.png`(600dpi) |
| 画布 | `figsize` 宽度固定 **6.1 英寸**（对应正文 15.5 cm），高度见各图；`bbox_inches="tight"` |
| 字体 | `Source Han Sans`（路径见下），`font.size: 7`，图内标注 5.5–6.5 pt，面板字母 9 pt 粗体 |
| 配色 | 只用三色：`GRAY="#1a1a1a"`（主体）、`MID="#6b6b6b"`（次要/虚线）、`ACC="#b3261e"`（本方案强调）。**不要彩色** |
| 线宽 | 轮廓 0.6–0.8，强调 1.0–1.4，虚线 `ls="--"` 或 `":"` |
| 面板标签 | 左上角 `a`、`b`、`c`，9 pt bold，`transAxes` 坐标 `(-0.02, 1.02)` |
| 导出 | `svg.fonttype="path"`（中文转路径，避免字体依赖）、`pdf.fonttype=42` |
| 禁止 | 阴影、渐变、3D、图例框、超出本规格的装饰 |

字体加载样板（每张图都要）：

## 1 `schema-1-monitor.svg` — 物理作战域三维监控智能体

**要表达的一句话**：监控是唯一的公共底座，它的输出只有"弹型 + 弹速"两个字段，而这个输出在实现上是缺失的。

**画布**：6.1 × 2.4 英寸，单面板 `a`（或两栏 `a`/`b`，见下）。

面板 **a**（左 55%）——"一进三出"结构：

1. 左侧一个竖直细长框，标 `战场态势（只读）`，框内画 3 条小曲线段表示来袭弹轨迹（用 `GRAY` 细线）。
2. 中间一个加粗边框矩形（`ACC`，lw 1.2），标 `物理作战域三维监控`；框内分三行小字：
   - `筛选：指向本方的弹`
   - `输出：弹型 ＋ 弹速`
   - 第三行用**虚线小框**标 `判定算法未实现`（`MID`，虚框）
3. 右侧三个小方块竖排：`飞机`、`船`、`地空导弹营`。箭头由中间框指向三个小方块，箭头旁分别标 `时刻调用`。
4. 中间框与左框之间一条粗箭头，标 `每步观测`。

面板 **b**（右 45%）——判定几何：

- 画我方单位 `M`（实心圆点，`GRAY`）与来袭弹 `P`（三角形，`ACC`）。
- 画两者连线（虚线）并标注 `d`；在 `P` 处画速度矢量箭头，与连线的夹角标 `θ`。
- 画 `P` 的速度延长线（虚线，指向 M 方向），表示"是否指向自己"。
- 右上角一个小注：`判据示意 · 实现未给出（存疑 E1）`，字号 5.5。
- 下方画一条距离轴：横轴 0→30 km，在 `R_kill = 0.1 km` 与 `d_min` 处各画一条竖直虚线，标 `最近接近点`。

**必须出现的文字**：`监控`、`弹型`、`弹速`、`时刻调用`、`未实现`。

## 2 `schema-2-sam.svg` — 地空导弹营攻击与自卫

**要表达的一句话**：三条规则构成一个二分支循环，其中"3/5 Dmax"是唯一的量化阈值。

**画布**：6.1 × 2.6 英寸，两面板 `a`（左，状态机）`b`（右，几何）。

面板 **a** 状态机（三个节点）：

- 节点 1 `常态`（圆角矩形）→ 节点 2 `开雷达 + 自由开火 + 停车`（上方）与 节点 3 `关雷达 + 加速跑`（下方）。
- 判据菱形：`监控返回来袭弹？`，两条出边分别标 `否` / `是`。
- 由节点 3 回到菱形一条回路，标 `弹消失`。
- 在节点 2 下方引出一条红色小分支：`d ≤ 3/5 D_max → 发弹`（`ACC`，lw 1.2）。

面板 **b** 射程几何：

- 以左下角为阵地 `SAM`（方块），画两个同心圆：半径 `D_max`（实线，`MID`）、半径 `0.6 D_max`（虚线，`ACC`）。
- 圆的半径用实际比例：`D_max = 100.8`（图内单位可缩放到 1.0），`0.6 D_max = 60.5`。
- 从右上方画一条目标航迹箭头（直线，指向 SAM），与 `0.6 D_max` 圆交点处画一个红色星号，标 `发弹点`；与 `D_max` 圆交点标 `最大可拦截边界`。
- 在两个圆之间用双箭头标注 `0.4 D_max`（能量裕度区），文字 `能量裕度`。
- 右下角小字：`D_max 由模型二分求得，非外部给定`。

## 3 `schema-3-evasion.svg` — 空战单元自卫

**要表达的一句话**：掉头距离必须大于 d₀；分档规则的两个常数在中间弹速段都落在 d₀ 的错侧；垂直扭动只改变视线角速度，不改变能量结局。

**画布**：6.1 × 4.4 英寸，2×2 面板 `a b / c d`。

面板 **a** 三段式规避几何（俯视图，等比例）：

- 我方飞机在左，来袭弹在右，两者迎头。
- 画三条水平虚线，分别标 `10 km`、`20 km`、`50 km`（`LIGHT`/`MID`），表示三个可能的掉头位置。
- 在 `50 km` 处画掉头弧线（`ACC`，lw 1.2），标 `① 掉头 + 加力`；弧后接一条背向直线。
- 在 20 km 处画一条垂直于弹方向的锯齿线（3 个折返），`ACC` 虚线，标 `② 垂直扭动`；并画一条细箭头标 `缩短分离速度 →`。
- 右上角标 `V弹 = 3000 km/h` 与 `d₀ = 58.8 km`；用一条粗红竖线在 58.8 km 处标 `d₀`，让学生一眼看出 50 km 落在 d₀ 内侧。

面板 **b** 视线角速度（说明"垂直扭为什么在几何上几乎无收益"）：

- 横轴 `d / km`（0–25，对数或线性皆可），纵轴 `ω_LOS / (°·s⁻¹)`。
- 画曲线 `ω_LOS = V_a / d`（取 `V_a = 0.30 km/s`，换算为 °/s）。
- 画水平线 `ω_max = 25 °/s`（`MID`，虚线），交点处竖直虚线落到横轴，标 `d_c ≈ 0.69 km`。
- 阴影区（`LIGHT`，alpha 0.3）覆盖 `d > 5 km`，标 `该区间几何脱靶量可忽略`。

面板 **c** 弹速—时间与反打点：

- 横轴 `t / s`（0–240），纵轴 `弹速 / km·h⁻¹`（0–3500）。
- 画两条衰减曲线：`V0 = 2500` 与 `V0 = 3500`（`GRAY`/`ACC`）。
- 水平虚线标 `500`，两条曲线的交点用圆点标出，并标 `反打点`；第二个交点上画向下箭头到横轴，标 `t*`。
- 在 `500` 线以下用浅灰填充，标 `能量耗尽区`。

面板 **d** 裕度条形图（数据固定，直接照抄）：

| V弹 | d₀/km | 规则取值/km | 裕度 |
|---|---|---|---|
| 1500 | 12.0 | 20 | 1.67 |
| 2000 | 26.9 | 20 | 0.74 |
| 2500 | 42.7 | 20 | 0.47 |
| 3000 | 58.8 | 50 | 0.85 |
| 3500 | 75.1 | 50 | 0.67 |

- 横轴 `V弹 / km·h⁻¹`，左纵轴 `距离 / km`：画两组柱（`d₀` 用 `MID`，规则取值用 `LIGHT`），并在柱顶标数值。
- 右纵轴 `裕度`：画折线（`ACC`，带圆点）；在 `1.0` 处画水平虚线，标 `裕度 = 1（临界）`；裕度 < 1 的点用实心红点，其余用空心。
- 图例只用一个：`d₀`、`规则取值`、`裕度`。

## 4 `schema-4-aircombat.svg` — 空空作战

**要表达的一句话**：开火时机由 d₀ 判定；固定常数在尾追段必然落空；高低差通过比能量改变 d₀。

**画布**：6.1 × 2.7 英寸，三面板 `a b c`。

面板 **a** 三态势（三个小俯视图横排，共用比例尺）：

- 左：`迎头`——两机相向，速度矢量对指，中间标 `d`。
- 中：`切向`——两机航向夹角约 60°，标 `θ`，旁注 `命中概率最高`。
- 右：`尾追`——敌机在前逃逸，我机在后追，标 `V敌`、`V弹`。
- 三个小图用同一虚线圆标 `0.8 d₀`。

面板 **b** 先射时间差（数据固定）：

| 策略 | 开火距离/km | 命中率 | 先射时间差/s |
|---|---|---|---|
| 0.8 d₀ | 30.1–51.4 | 1.00 | +46.7 … +83.3 |
| 固定 30 km | 30.0 | 1.00 | +63.5 … +83.4 |
| 固定 60 nm | 111.1 | 0.00–0.12 | 0 |
| 最大射程 90 nm | 166.7 | 0.00 | −43.5 … −57.1 |

- 横轴：四种策略（两行文字标签）。
- 左纵轴：命中率，柱状（本方案用 `ACC`，其余 `LIGHT`/`MID` 灰阶）。
- 右纵轴：先射时间差，折线 + 圆点（`ACC`）；在 0 处画水平线并标 `先射权分界`。
- 正负号要用箭头示意：正区标 `本方先开火`，负区标 `对手先开火`。

面板 **c** 高低差剖面：

- 侧视：横轴 `距离`，纵轴 `高度`。
- 画目标机在 8 km 高度、我方在 10 / 8 / 6.67 km 三个高度各画一条水平线（`MID` 虚线），并在右侧标 `d₀ = 44.4 / 37.6 / 33.3 km`。
- 从发射点到目标画三条抛物线式轨迹（示意导弹爬升/俯冲），俯冲轨迹用 `ACC`，爬升轨迹用 `MID`。
- 标 `Δh` 与 `Δd₀ = ±18% / −11%`。

## 5 `schema-5-ship.svg` — 登陆船只集群自卫

**要表达的一句话**：处置由"弹型 × 区域"的笛卡尔积决定；三类威胁对应五种手段；第三类的关键不是舰，是照射机。

**画布**：6.1 × 3.0 英寸，两面板 `a`（左，海域）`b`（右，决策表）。

面板 **a** 海域示意（俯视，简化）：

- 画一个不规则海岸线（用 8–10 个点的折线，`GRAY`，lw 0.6），海区用极浅灰填充。
- 在海上用**两个多边形**划出 `ABDE 区`（虚线边界，`MID`）与 `C 区`（点划线边界，`ACC`），并在区内标区域名。
- `ABDE 区` 内画两艘护卫舰图标（简单梯形，标 `雷鸣号 1`、`雷鸣号 2`）；`C 区` 内画一艘船坞登陆舰（长方形，标 `23900 舰`）并在其上方画激光束（`ACC` 细直线到一枚来袭弹）。
- 画四枚来袭弹（三角形）与航迹箭头：两枚指向 ABDE 区（标 `卢卡斯`、`海马斯`），两枚指向 C 区（标 `卢卡斯`、`158C`）。
- 在 23900 舰上空画一架小型飞机（`苏-57`），并用曲线箭头标 `召机驱离照射机`；在更远处画敌方照射机（小三角，`MID`），二者之间画一条照射线（点线），标 `持续照射`，再画一条红色断开符 `×` 表示被打断。

面板 **b** 决策矩阵（用 `table`-style 网格，不要用 matplotlib table）：

- 3 行（一类/二类/三类）× 3 列（区域 / ABDE 处置 / C 处置）。
- 单元格内文字：
  - 一类｜卢卡斯｜`雷鸣号 d<3 km 自卫`｜`不拦 → 23900 激光`
  - 二类｜海马斯 / 反舰导弹排｜`雷鸣号 D_max 开火`｜`一号 D_max，二号 ½D_max 补拦`
  - 三类｜158C / 154C｜`关雷达 + 切向背身 + 加力；召苏-57`｜`同左`
- 表头用 `GRAY` 0.8 实线下划，行间用 `LIGHT` 0.4 细线。
- 在"一类"行的 C 区单元格用 `ACC` 底色浅红（alpha 0.08）强调。
